Design notes for review

Only the four Activity cards come from the new backend. Everything else is plain markdown and shields.io badges. The numbers on the cards are your real commit history from the repos on this machine (languages excepted, which are illustrative). The live service will read the same figures from GitHub's API using your token, so private organisation work counts too. The dashed outline in the sidebar marks a suggested new bio, which you set in your GitHub profile settings. The "Pinned" row is also a suggestion, set from your profile.

CardEndpointShows
OverviewGET /v1/cards/overview?theme=light|darkCommits in the past 12 months as the one headline figure, plus active days, longest streak and current streak
MonthlyGET /v1/cards/monthly?theme=Commits per month for 12 months. Grey columns, with the current month in the accent. Only the peak and the latest month carry a value label
ProjectsGET /v1/cards/projects?theme=Commits per project, all time. A config file maps repos to project names, so private organisation repo names never appear on the card. ORG or OWN is shown as text, not colour
LanguagesGET /v1/cards/languages?theme=Top 5 languages by bytes, plus "Other". GitHub's language colours, adjusted so each one is distinguishable and readable on GitHub's light and dark backgrounds (checked with a palette validator)

Each card has a light and a dark version, picked by GitHub's own theme through <picture>. No gradients, no shadows, hairline borders, one accent per card. GitHub serves README images as static pictures, so the cards can't have hover tooltips; every value that matters is printed on the card. No deployment URL yet, so the README draft uses a STATS_HOST placeholder.
