## 📦 Open source

- **[@reactmode/unused-file-detector](https://www.npmjs.com/package/@reactmode/unused-file-detector)**: finds files whose exports are never imported, and dependencies nothing uses. `npx @reactmode/unused-file-detector`

## 🧭 How I work

- **Small files, strict layers.** Controller → service → repository, never skipped.
- **Typed end to end.** Strict TypeScript from schema to button, Zod wherever data enters.
- **Built for the network people actually have.** Persisted caches, optimistic writes, real offline states.
- **Design systems, not screens.** Semantic tokens and a shared primitive set, so dark mode isn't a bolt-on.
